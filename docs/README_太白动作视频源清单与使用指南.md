## 二、如何使用这些视频复刻武侠骨骼动作

1. **直接在工程台中加载**：
   - 打开 **MotionStage 3D 动作工程台**，点击顶部栏 **「导入视频提取」**（或直接将上述 `01b` / `02` / `03` / `04` 任意 `.mp4` 拖入舞台画面）。
   - 系统会自动运行 **MediaPipe Pose Landmarker Heavy (33点 3D 姿态)** + **手掌三点正交基 6自由度剑向解算** + **零相移双向低通滤波** + **双骨解析 IK 防滑步锁脚**。
   - 点击底部栏 **「佩剑」** 即可挂载武侠长剑并查看剑锋刀光轨迹；点击顶部 **「导出 BVH」** 即可下载标准 `.bvh` 骨骼动画文件导入 Blender / Unreal / Unity。

2. **B站 / YouTube 玩家实录补充说明（双向云盘联动）**：
   - B站与 YouTube 平台带有防爬签名校验，云端工作台遵循安全规范不直接绕过抓取；如果你自己在浏览器中保存了 B站太白技能单人木桩演示视频（推荐纯背景、单人全身出镜、无频繁镜头切换的实录，例如 `BV14t4y1k7ib` 太白招式拆解、`BV1ab411U73b` 全门派技能展示），只需将 `.mp4` **直接拖进当前这个 Google Drive 文件夹**（或直接拖进 MotionStage 网页舞台），我这边也能直接从你的 Google Drive 同步读取并帮你做批量动作切分与骨骼清洗！
