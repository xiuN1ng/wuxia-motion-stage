## 🚀 本地电脑 30 秒离线启动指南

### 方式一：二次开发模式（推荐，支持修改骨骼与清洗参数）
1. 下载 `03_MotionStage工程源码与离线部署包/MotionStage_完整源码工程_含离线AI分片.zip` 并解压。
2. 在终端进入解压目录（需安装 Node.js 18+）：
   ```bash
   npm install
   npm run dev
   ```
3. 浏览器打开终端提示的本地地址即可使用：
   - **无需翻墙或外网下载模型**：`public/mediapipe/chunks/` 已内置 `pose_landmarker_heavy` 模型与 WASM 分片。
   - **拖拽即提取**：将 `01_参考视频源库` 或你自己的单人武术/游戏木桩 `.mp4` 拖入窗口，自动完成 3D 姿态提取、手腕剑向解算、防滑步 IK 清洗，一键点击 **「导出 BVH」**。

### 方式二：免编译即开即用模式
1. 下载 `MotionStage_Web静态免编译部署包_dist.zip` 并解压。
2. 在解压目录运行任意本地静态服务即可（例如 Python）：
   ```bash
   python3 -m http.server 8080
   ```
3. 浏览器访问 `http://localhost:8080` 即可直接使用全部功能。
